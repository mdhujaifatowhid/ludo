Drop your own short sound effect files here with these exact names:

  dice.mp3      - dice roll / tumble
  move.mp3      - token moving a square
  capture.mp3   - sending an opponent's token home
  home.mp3      - a token reaching the home column
  win.mp3       - a player finishing the game
  message.mp3   - new chat message
  join.mp3      - a player joining the room

Free sources: freesound.org, mixkit.co/free-sound-effects, zapsplat.com
(check each clip's license). Keep files small (<50KB) so they load instantly.
The app works fine with these files missing — playback failures are caught
silently — but sound effects won't play until they're added.
